# Welcome to my blog

This is a simple example post demonstrating the new blogging infrastructure. Future posts can be written by creating a new folder in `app/blog` and adding a `page.mdx` file.

The blog listing page automatically uses the metadata exported from each post so everything stays in sync.

## Features

- **MDX Support**: Write in Markdown with React components
- **Automatic Styling**: Global MDX components provide consistent styling
- **Dark Mode**: Full dark mode support
- **Typography**: Beautiful typography with Tailwind CSS
