# Getting Started with MDX

MDX is a powerful format that lets you write JSX in your Markdown documents. This makes it perfect for creating rich, interactive blog posts.

## What is MDX?

MDX allows you to use React components directly in your Markdown content. This means you can:

- Write normal Markdown content
- Import and use React components
- Create interactive examples
- Build rich, engaging content

## Writing Your First Post

To create a new blog post, simply:

1. Create a new folder in `app/blog/` with your post slug
2. Add a `page.mdx` file with your content
3. Export metadata at the top of the file
4. Write your content in Markdown

```javascript
export const metadata = {
  title: "Your Post Title",
  description: "A brief description",
  date: "2024-01-15",
}

# Your Post Title

Your content goes here...
```
